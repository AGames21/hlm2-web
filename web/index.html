Keyboard and mouse

Click a key to change it. Arrow keys also move. Aim with the mouse; left click attacks, right click picks up or throws. On a trackpad, use the Attack, Pick up and Lock on keys instead. Escape cancels a key change.

Play Hotline Miami 2 in your browser

  1. Find hlm2_data_desktop.wad in your own Hotline Miami 2 install (Steam: right-click the game → Manage → Browse local files).
  2. Click Load game files above and pick it, or drag it onto this page. Add hlm2_music_desktop.wad too if you want the game's music.
  3. The title menu starts. Pick NEW GAME.

Your files stay in this browser and are kept for next time, so you only do this once per device. Nothing is uploaded.
